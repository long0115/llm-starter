# 报销流程

## 第一章 报销类型

### 1.1 差旅报销

#### 适用范围

员工因公务需要出差产生的交通、住宿、餐饮等费用。

#### 报销标准

| 费用类型 | 标准 | 说明 |
|---------|------|------|
| 机票 | 经济舱 | 需提前 3 天预订，特殊情况可乘坐商务舱 |
| 高铁 | 二等座 | 行程超过 4 小时可乘坐一等座 |
| 住宿 | 一线城市 500 元/晚，二线城市 350 元/晚 | 超标部分自理 |
| 餐饮补贴 | 100 元/天 | 无需发票，按天计算 |
| 市内交通 | 实报实销 | 出租车/网约车，需注明行程 |

#### 报销材料

1. 出差审批单
2. 交通票据（机票行程单、高铁票）
3. 住宿发票
4. 其他费用发票

### 1.2 业务招待报销

#### 适用范围

因业务需要宴请客户、合作伙伴产生的餐饮费用。

#### 报销标准

| 招待对象 | 标准（人均） | 审批要求 |
|---------|------------|---------|
| 普通客户 | 200 元 | 部门负责人审批 |
| 重要客户 | 500 元 | 分管副总裁审批 |
| 战略客户 | 1000 元 | CEO 审批 |

#### 注意事项

- 报销时需注明招待对象、人数、事由
- 单次招待超过 5000 元需提前申请
- 严禁报销娱乐场所消费

### 1.3 办公用品报销

#### 适用范围

部门日常办公所需的文具、耗材、设备等。

#### 报销流程

1. 部门助理统一采购
2. 填写采购申请单
3. 行政部审核
4. 财务部报销

#### 标准

- 单次采购 500 元以下：部门负责人审批
- 500-5000 元：行政部审批
- 5000 元以上：分管副总裁审批

## 第二章 报销流程

### 2.1 报销步骤

```
1. 收集发票 → 2. 填写报销单 → 3. 主管审批 → 4. 财务审核 → 5. 打款
```

### 2.2 时间要求

| 环节 | 时限 |
|------|------|
| 发票开具后报销 | 30 天内 |
| 主管审批 | 3 个工作日内 |
| 财务审核 | 5 个工作日内 |
| 打款 | 审核通过后次月 15 日 |

### 2.3 发票要求

- 必须是**增值税普通发票**或**增值税专用发票**
- 发票抬头：星辰科技有限公司
- 税号：91110108MA01XXXXX
- 发票内容必须与实际消费一致
- 电子发票需打印后粘贴在报销单后

## 第三章 常见问题

### 3.1 发票丢失怎么办？

- 交通票据：到售票处开具证明
- 增值税发票：到开票方复印存根联并加盖公章
- 其他发票：写情况说明，主管签字确认

### 3.2 报销被退回怎么办？

- 查看退回原因（发票不合规、信息填写错误等）
- 补充材料后重新提交
- 如有疑问，联系财务部报销专员（分机：8001）

### 3.3 加急报销

- 特殊情况可申请加急报销
- 需部门负责人签字说明原因
- 财务部 3 个工作日内完成审核打款
